# Módulo 3: Taller de Fotografía Técnica

> 🚧 **En preparación.**

## Descripción
Aplicación de la fotografía como herramienta de registro técnico en ingeniería, siguiendo el material del curso [Fotografía Digital para ingenieros](https://github.com/ricardorpalma/Fotograf-a_Digital):

1. **La imagen como documento técnico:** fotografía sin filtros ni edición, conservando metadatos.
2. **Encuadre estructurado:** regla de los tercios y secuencia plano general → plano medio → detalle.
3. **Iluminación técnica:** luz rasante para revelar texturas, grietas y desgaste; control del balance de blancos.
4. **Escalas y contexto:** referencias de medida para que los defectos registrados sean medibles.
